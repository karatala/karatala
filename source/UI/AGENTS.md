# Purpose

- Own the plugin editor's panels, controls, visual theme, responsive layout, and user interaction.

# Ownership

- `UITheme.h` and `LookAndFeel*` own shared visual tokens and JUCE drawing behavior.
- `ThemePlaygroundPanel.*` owns the live component, font, and color inventory used to review theme consistency.
- `LibraryArticulationEditor.*` currently owns library kit corrections, previews, copied measurements, and live recipe status.
- `KitPage.*` owns complete library-kit loading, preview, and instrument-map preset actions.
- `CompactModalDialog` owns small editor-contained value-entry and confirmation dialogs.
- Reusable controls live in `Parameter*`, `CompactParameterControl`, `HorizontalKnobBrick`, MIDI assignment, popup, and helper classes.
- Page and panel classes compose controls and translate user actions into engine operations.

# Local Contracts

- Reuse `UITheme`, `LookAndFeel`, and `UIHelpers` instead of hard-coded styling.
- Settings shown as live must update audio-thread-visible state through a thread-safe engine API.
- Keep persistence debounced and outside the audio thread.
- Preserve keyboard, tooltip, and resize behavior when adding controls.
- Zone pads use a vertical instrument-name rail, equal rows for normal articulations, and a Hi-Hat grid ordered tight/close/half/open with pedal as a full-width bottom row. Painting and hit testing must share the same cell geometry. Hi-Hat states without their own MIDI note stay visible and preview the loaded controller sibling directly without sending CC.
- Instrument-map editors preserve exact hi-hat articulation-slot expressions such as `bow[open]` and `bow[tight]`. When an editor changes a legacy base articulation slot, it can anchor the library-articulation family to the matching slot expression. It must not change an explicit remap.
- Pad-popup mic routing shows output names but selects and saves each mic-layout output's stable semantic ID, so repeated output codes remain separate choices across layout reordering.
- Pad-popup routing choices use the engine's mic-output matcher, including independent type and position wildcards such as `**m`, `*tm`, and `d*m`.
- Pad-popup map-layer controls update only their own articulation slot and map layer. Removing an unmapped empty row must not reapply the instrument map.
- Pad-popup `CompactParameterControl` changes update runtime audio and linked visible controls immediately. Full map serialization, editor notification, and one preview of the latest changed articulation happen once after 250 ms without another value change. Mouse drag and wheel changes use this same debounce and must not preview directly from drag-end callbacks.
- The pad popup edits a map layer's velocity-to-dB curve through one compact dropdown below Tuning, Attack, and Decay. The dropdown offers `Global Vel-to-dB curve`, built-in Linear, Logarithmic, and Exponential curves, every user preset, and `Edit curve...`. An unmatched inline definition displays as `Edited Map Layer Curve*` but is not a selectable preset. The Instrument page shows `Global`, a matching preset name, or edited status. Shared map serialization must preserve velocity response, bleed, and mic-route fields.
- The velocity-to-dB editor uses about 60% of its host width, 55% of its host height, and two equal columns. The left column contains only the graph without axis labels, vertical guides, or fitted-level markers. Its vertical position is linear output gain, so the Linear built-in appears straight, while editing and readouts stay in dB. Draw the response as a 3 px line and show a thin horizontal guide at the cursor. The right column contains the two-line `Articulation slot / library articulation (map layer N)` and `Library kit / instrument / articulation` title plus all controls. Omit the map-layer suffix for map layer 1. The graph is editable immediately. The first graph or numeric change while using the global curve copies it into a map-layer override. Selection without a value change keeps the global mode. Hovering anywhere in the graph for 120 ms converts the cursor Y position to dB, finds the nearest velocity on the current response, and previews that exact map layer once. A simple click also previews without requiring movement. A recent matching hover suppresses the duplicate mouse-up preview. A changed drag previews once on mouse-up, and stationary hover does not repeat. Keep recorded sample, raw median, and calibration details in the tooltip. Save reusable curve-only presets separately from kit-layout presets.
- Exact pad-popup map-layer rows show a hover-only gear button in the library card's top-right corner. The library-articulation editor changes library-wide velocity ranges, library-instrument or library-articulation placement balance, whole-file manual gain, and whole-file or per-mic playback offsets. The editor uses normal text, a round robin by velocity multi-select matrix, mic filters, a selected-file list, and three batch fields. The matrix opens without a selected or active hit. Clicking `*` inverts every existing matrix cell. Clicking a round robin ID inverts that row. Clicking a velocity heading inverts that column without preview. Its header and round-robin-ID column use centred content. Its five value editors use the standard 20 px control and 14 px vertically centred text style, preserve typed, inherited, and `Mixed` values, and support coarse wheel or fine Shift-wheel changes. Effective velocity ranges use compact two-line blocks with a smaller range line. `Even` distributes the full MIDI range across all velocity levels in one save. `Reset` restores filename ranges. Filename range details and generated sample measurements stay available in tooltips. Matrix preview plays the complete linked logical hit. Mic preview solos one exact mic without advancing normal round robin. A matrix or mic click cancels the queued hover for that same target, so it produces one preview. Successful value-editor commits preview the complete logical hit from the last selected-file row, while range actions preserve their own preview target. Batch values persist through one complete library kit override save. Save failures keep the editor open and offer retry or explicit reload of saved override values. The editor must not rewrite instrument-map fields.
- The Conf page General section owns the sample-library path, sample-cache limit, current-instance `Global Velocity-to-dB Curve`, and machine-wide default kit and mic layout controls. The global curve dropdown offers built-in and user presets, shows `Unnamed global curve*` for an unmatched stored definition, applies live to map layers without an override, and saves only to plugin instance state. Changing the library path reloads the library. Layout defaults affect future plugin instances.
- The shared library picker is a centered modal that uses 80% of its host content area, with a dark click-to-dismiss outside overlay. Its panel has 6 px rounded corners, 4 px inner padding, and no outline border.
- The picker title row shows the articulation-slot context and a `×` close button on the right. Whole-instrument context is only the instrument-slot display name, such as `Tom 1`. Articulation-slot context is `Kick / center`, with ` (map layer X)` only when `X` is greater than 1.
- The picker supports `-word` exclusions, OR-based multi-select base-articulation filters, arrow-key preview, and Enter to use. Opening it for an assigned row filters by the assigned library-instrument type before the instrument-slot type. It then preselects and scrolls to that library item without previewing it. Adding a map layer opens the picker immediately for the new empty map layer.
- The shared library picker has an explicit whole-instrument mode. This mode shows each library instrument once in the main list and its library articulations in a separate preview-only list. It has no hidden instrument-slot type restriction. Selection removes all existing map layers for the instrument slot. It creates one map layer for each library articulation with a required articulation-slot target. It uses an exact match first, then the configured instrument-type fallback order, and shows every fallback or skip warning. Category and Types controls remain available as manual filters.
- The Kit page has Library Kits and Presets sections, kit metadata, read-only text, and an articulation preview grid. Library preview does not change the active instrument map. Loading a library kit or preset replaces only the instrument map. It keeps the active kit layout and MIDI notes. The app skips preset entries for missing layout slots and shows a status message.
- Kit-page preset actions load factory or user presets and save, save as, or delete user instrument-map presets. A preset stores only normalized instrument-map text, including map layers and their settings. `Save` overwrites only the selected user preset. `Save As` rejects an existing user preset name case-insensitively across supported preset file extensions.
- The sidebar owns user-facing pages except Logs and includes one Kit page. The existing troubleshooting page opens from the `Logs` status-bar button instead of a sidebar button. In debug builds, the right-side status-bar order is `UI`, `?`, `Logs`. In release builds, `?` is hidden and `Logs` stays at the far right.
- Text editors have no normal, focused, or shadow outline.
- Standard buttons, toggles, dropdowns, and menu text use the shared 20 px control height with normal 14 px text.
  The pad-popup library-picker card and compact mic-routing dropdown keep their purpose-specific sizes.
- Dialog headers use the shared icon-only `×` close-button style. Velocity-to-dB Curve, library-articulation editor, library picker, and other dialogs must not use a text `Done` button.
- Preset name, clone, replace, delete, and small value-entry dialogs use `CompactModalDialog`, stay clipped inside `PluginEditor`, and use a dark click-to-cancel overlay. They use content-sized panels, shared 20 px controls, Enter to confirm, and Escape, the header `×`, or an outside click to cancel. Validation errors stay inside the same dialog.
- `CompactParameterControl` keeps its existing value font. The Instrument page uses label-free table-row bounds. PadPopup uses 32 px controls with the existing 10 px label.
- Instrument and Map tables use fixed 18 px headers, 22 px rows, shared 90/100 px instrument and articulation columns, and normal 12 px name text.
- Pad-popup instrument and articulation headings use the same normal 12 px name text.
- The pad popup is bottom-docked at 90% of the page-content height and uses the full page-content width. Its uncovered top strip is dark, closes the popup when clicked, and contains a large white `×` aligned left. Switching pages also closes the popup. The popup keeps rounded top corners, square bottom corners, and no outline border.
- Pad-popup map-layer group backgrounds end at the bottom of the velocity-to-dB and mic-routing controls without extra bottom padding. Library cards use centred vector icons, with library-articulation editing at the top-right and map-layer removal at the bottom-right. Both icons appear only while their library card is hovered. The `L/R` button must show its full text.
- When a PadPopup child dialog is open, an outside click in either the dialog overlay or the uncovered top strip closes only that dialog. A later outside click can close the PadPopup.
- The pad-popup header order is instrument-slot title, `LINK ARTS`, conditional `LINK TOMS BLEED`, `SET INSTRUMENT`, and right-aligned MIDI controls. `SET INSTRUMENT` removes every map layer for the current instrument slot and installs one complete library instrument through the surgical instrument-slot change path.
- `LINK ARTS` applies tuning, attack, decay, gain, pan, L/R flip, phase flip, one changed bleed mic level, or one changed mic route to the same map-layer number across the current instrument slot's articulation slots. Missing map layers and missing mic codes are skipped.
- `LINK TOMS BLEED` is available only on Tom instrument slots and applies the changed mic code's level or route to every map layer and articulation slot in every Tom instrument slot. Routing copies `Auto`, `Unassigned`, or the selected stable output ID. Targets without that compatible output choice are skipped. When both links are active, target map layers are deduplicated.
- Linked changes update only the changed field, update visible controls without recursive callbacks, persist one serialized instrument map, and notify the editor once. Parameter and mic-route runtime batches each use one engine graph lock. Link modes are temporary, reset when the popup closes, and use a steady bright-red fill with white text and a clear border without blinking.
