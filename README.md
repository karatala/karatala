# Karatala Drum Kit Engine

Karatala is a virtual instrument with advanced drum kit related features for use with e-Drums and without.

Play drum sounds with an electronic drum kit, a MIDI keyboard, standalone or in your DAW or any other music app with virtual instrument support (VST/CLAP/AU).

## What it can do

- Multiple velocity layers support (Soft and hard hits of defferent gradation can use different recordings)
- Round-Robin (Use different recordings for repeated hits)
- CC and Polyphonic aftertouch (Follow the hi-hat pedal and support cymbal choke messages from your e-drum kit)
- Choose drum sounds, combine sound layers, and save your own kits
- Customizable velocity response and other params like tuning, volume, pan, attack, decay and individual mic gain if instrument has multiple microphone recordings
- Multi-mic sample libraries support (create own mic map and auto set microphone sounds to separate named outputs in your DAW)
- Use drum layouts for any supported  MIDI e-drum kits - Alesis, Roland or any other modules, or set your own MIDI mappings.
- Run as a separate app, or as a VST3 or CLAP plugin. macOS also has an AU plugin.
- Create your own instruments from your recordings with the [sample folder and file format](docs/SAMPLE_LIBRARY_FORMAT.md).
